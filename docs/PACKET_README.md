# humanity-succeed — terminal-agent specification packet

This packet specifies a local research repository. **It does not contain the implemented application, a trained adapter, a model evaluation, or an approved preregistration.**

Read `TERMINAL_AGENT_PROMPT.md` to assign the build. The authoritative requirements are `BUILD_SPEC.md` and `docs/PROTOCOL.md`; `AGENTS.md` defines the first stop and work boundaries.

The project asks whether a reviewed curriculum can improve truthful, corrigible, agency-respecting assistance—including affirmative help, learning, creation and user-valued features—beyond ordinary procedural practice and the same principles supplied as instructions.

The first deliverable is an offline instrument: separate subject and evaluator views, strict synthetic actions, verifiable effect records, deterministic commissioning, blinded review packets and honest study planning. Real model use and weight changes remain explicitly gated.

## Packet contents

- `BUILD_SPEC.md`: architecture, contracts, scope, CLI, work packages and acceptance tests.
- `AGENTS.md` and `TERMINAL_AGENT_PROMPT.md`: builder assignment and boundaries.
- `docs/PROTOCOL.md`: experimental cells, units, pilot workload, proposed inference and failure semantics.
- `docs/DECISIONS.md`: adopted/corrected/deferred points from the relay.
- `docs/PREREGISTRATION_DRAFT.md`: unfilled research registration and approval template.
- `docs/THREAT_MODEL.md`: practical security and validity boundaries.
- `docs/SOURCE_REGISTER.md`: source status and verification limits.
- `schemas/`: reference JSON Schemas to implement and extend under version control.
- `examples/`: invented, AI-authored commissioning-development fixtures; not human-reviewed training data.
- `configs/`: draft settings and a calculated workload example, never execution approval.
- `PACKET_MANIFEST.json`: hashes of packet artifacts and validation notes.

`hs` commands throughout this packet are target interfaces for the terminal agent to implement. No `hs` command is claimed to exist yet. No public repo, library upload, model download, training run or Stack write was performed in producing this packet.
