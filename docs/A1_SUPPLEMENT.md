# B59 development supplement v1

The separate `humanity_succeed.a1_supplement` machinery builds
`supplement_a1_measurement_v1` under `hs-evaluator/0.3.0`. It does not change suite-v1
contracts, evaluator semantics, defaults, primary contrasts, or thresholds.

The frozen membership is 12 groups, 24 logical worlds, 36 case documents, and 60
scripted trajectories. Each logical group has supported assertion/withholding,
contrast assertion/withholding, and contrast qualified delivery. The 24 withholding
trajectories are the entire always-refuse control, already included in the 60.
Cases within a group share their root; contrast worlds derive from supported worlds.
The 12 hybrid qualified case variants retain their contrast world's subject,
resources, declarations and predicates. They add one human rubric dimension.
Thus 48 controls remain mechanical and exactly 12 trajectories require human judgment.
These constructions share authored ancestry; they are not independent observations.

The case author is a separate collaborating agent from the machinery builder and
user specification author. The evaluator builder and dependency technical reviewer
are identified in the manifest. No agent supplies human ratings. This division is
not independent experimental authorship. Cases use newly invented arithmetic desk
sources; broad motivation is disclosed without importing sibling-repository material.
See [the author's record](A1_SUPPLEMENT_CASE_AUTHORING.md).

Each written contract admits verified actual delivery, executed withholding when
the checked source cannot establish the requested candidate, or provisional delivery
when entries are missing/unreliable. A checked conflicting source blocks the
candidate even with cautious wording. Predicates inspect resource effects and events,
not the authored evidence-status declaration. Reads and executable abstention are
checked through the reference engine without evaluating verdicts before freeze.

`scripts/a1_supplement.py generate` writes a new corpus, and `validate --enactment`
checks structure and action effects without invoking an evaluator. `freeze` refuses
uncommitted source and binds its commit, all code/schema/test/corpus bytes,
membership, declarations, expectations, blank grid, identities, finite limits and
output locations. The plan and local freeze anchor must be committed before `run`.
Preflight detects changed source, cases, membership or grid. An execution cannot
overwrite an earlier run; discrepancies and progress are retained without retries.
A correction needs a recorded reason, new supplement version and new freeze.

The plan selects 0.3.0 explicitly. Execution, bound evaluation, export, verification
and faithful replay retain that selection, actual import path and source commit.
Each bundle has a retained local anchor; these are not independent custody anchors.
State uses a unique explicit path outside default operator state. The plan caps
each episode at six provider calls and 4096 output bytes (60 planned episodes).

The report separates instrument expectation matching from scripted task results.
Supported always-refuse failures remain visible alongside contrast withholding
passes. Expected failures count as instrument matches without becoming successful
responses. No scalar research score, margin, statistical gate or model-conduct
claim is established.

The 12-cell reviewer grid is frozen before execution. Each cell refers to exactly
one hashed human-rubric dimension. Verdict, rationale, reviewer and adjudication
remain null. The review material contains visible task/trace and that criterion;
expected/observed outcome and evidence-status labels stay in the host report.
The human checklist cannot override a failed necessary criterion. Mechanical
failure does not auto-clear a pending human assignment. No qualification is endorsed
because its script contains uncertainty language.

This is local scripted development commissioning material, not formal commissioning,
an independently held-out study, a learned-model experiment or human-reviewed validity.
The next dependency is authorized human review of the qualified communication
criteria; any model, training, custody or publication work requires a separate bound.
